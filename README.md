
## Dev Burger

<p>Interface de Hamburgueria , com catálago de produtos que pode ser cadastrado e editado, que tem uma API criada para fazer o gerenciamento de produtos e pedidos, feita como atividade de aprendizado. 
Com a mentoria de Agustinho Neto(Back-End) e Rodolfo Mori(Front-End), no curso Desenvolvedor Fullstack, da escola  DevClub.</p>

[![Technologies](https://skillicons.dev/icons?i=js,html,css,react,styledcomponents,vite,materialui)](https://skillicons.dev)

## 🎯 Proposta / Objetivo  

- Site que uma implemetação de uma Hamburgueria com funcinalidades para usuarios e com aréa de administração.
- Para usuários, tela inicial com categorias e ofertas, parte de cardapio, checkout e pagamentos.
- Para administrador, aréa de visualização e edição de status de pedidos, tabela com produtos e edição e cadastro de produtos.
- Funcionar como um estudo prático para consolidar conhecimentos em React.js, JavaScript e Styled-Components 
- Projeto de aprendizagem — com back-end.

## 🔍 Possíveis melhorias 

- Responsividade em todos os layouts
- Descrições resumidas em cada produto, quantidades &  porções, alimentos ultilizados, avaliações de cada usuários.
- Aréa do admin, ser um sistema separado da parte de clientes.
- Mais opções para admin, nos produtos ter a opção de deletar, desativar e ativar pordutos.
- Filtragem de categorias na tabela, e visualização delas.


## 🚀 Como executar localmente  
Siga estes passos para rodar o projeto em sua máquina:

```bash
# 1. Clone o repositório
git clone https://github.com/RAGNAR303/DevBurger-Interface.git

# 2. Navegue até a pasta do projeto
cd DevBurger-Interface

# 3. Instale as dependências

yarn install

# 4. Inicie o servidor de desenvolvimento
yarn dev
